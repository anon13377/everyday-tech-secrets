Research: Operation Triangulation

iPhoneRead only

Kaspersky found an undocumented iPhone hardware feature (CVE-2023-38606) used in a zero click attack on iOS up to 16.6. It was presented at the 37th Chaos Communication Congress in December 2023. The takeaway is simple: keep iOS updated.

Kaspersky press releasekaspersky.com

Research: nRootTag

iPhoneRead only

George Mason University researchers tricked the Find My network into tracking non Apple Bluetooth devices, claiming about 90 percent success using many GPUs. Apple shipped a fix on December 11, 2024.

Control Claude Code from your phone (one account)

7 steps

Recommended path: official Remote Control on the Windows host, pinned to one account with CLAUDE_CONFIG_DIR. Sources: Anthropic docs.

  1. Create a dedicated folder for the one account, for example C:\ClaudeAcctA (absolute path).

    Source

  2. In a fresh PowerShell window set $env:CLAUDE_CONFIG_DIR="C:\ClaudeAcctA" and confirm ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN and CLAUDE_CODE_OAUTH_TOKEN are empty. Remote Control refuses API key auth and setup-token tokens.

    Source

  3. Run claude auth login, choose the claude.ai option, sign in to the one target account, then check with /status.

    Source

  4. Start claude remote-control from that same window (a small .ps1 launcher that sets the variable each time helps). Press spacebar to show a QR code for the phone.

    Source

  5. On your claude.ai account settings turn on Require trusted devices (currently beta) and enroll only your iPhone (on Team or Enterprise plans an Owner turns trusted devices on). Use the Claude iOS app or claude.ai/code to steer.

    Source

  6. Do not install claudecodeui or Happy for this. No ports are opened and no third party relay is involved.

    Source

  7. Never set ANTHROPIC_API_KEY globally on this host. In claude -p mode the key is always used when present, so runs would bill the key instead of the subscription.

    Source

Plain warnings.
  • An ANTHROPIC_API_KEY in the environment silently wins over your subscription in claude -p. source
  • Tokens from claude setup-token cannot run Remote Control. source
  • claudecodeui is reached at your IP and port; never expose it to the internet. source
  • Happy routes traffic through a relay and supports inviting others into a session; its encryption has no published audit. source
  • A lost phone with an SSH key or a signed in Claude app is a key to your PC. Revoke devices at claude.ai account settings. source

4

Console settings and Sony apps only. Each link was fetched and loaded.

01

Built-in accessibility suite

PS5EasySkill: none

System-level screen reader, captions, zoom, color correction, high contrast, button remapping, mono audio and voice chat to text. Game-level accessibility varies per game.

Sourceplaystation.com
02

PS Remote Play to phone, tablet or PC

PS5EasySkill: none

Stream your PS5 or PS4 games to a phone, tablet, laptop or desktop, even over mobile data. Sony says at least 5Mbps broadband is required and 15Mbps is recommended, and mobile data counts against your plan.

Sourceplaystation.com

USB extended storage for games

PS5EasySkill: none

Format a commercially available USB drive to hold game and app data and free up console space. PS5 games cannot be played directly from it, only copied back, while PS4 games can be played from it.

PlayStation App as a remote control

PS5EasySkill: none

The phone app can start game downloads, manage console storage, access PS5 captures, launch games and sign you in by QR code. It needs Android 6.0+ or iOS 12.2+ and a signed-in account.

Chromebook: productivity uses

5

Each link was fetched and loaded. Check your model and admin policy first.

01

Android apps from Google Play

ChromebookEasySkill: none

Install Android apps on supported Chromebooks and use them like phone apps. Only some models support it, admins may block it, and turning Play Store off erases app data. Productivity angle: run the eBay or Sheets mobile app in a window for quick listing checks and replies.

Sourcesupport.google.com
02

Chrome Remote Desktop

ChromebookEasySkill: none

Install it on a Mac, Windows or Linux computer, then reach that computer from a Chromebook or share it with a helper. A shared person gets full access to your apps, files, emails and history, so use it only on computers you own or are authorized to access. Productivity angle: reach a desktop with heavy spreadsheets or eBay tools from a light laptop.

Sourcesupport.google.com
03

Linux development environment

ChromebookMediumSkill: basic command line

Turn on a Debian environment from Settings to run Linux command-line tools, code editors and IDEs. It is off by default, setup can take 10 minutes or more, and it may be unavailable on work or school devices. Productivity angle: run scripts such as Python or csv tools to clean spreadsheet or eBay listing exports.

Sourcesupport.google.com
04

ChromeOS Flex on an old PC or Mac

ChromebookMediumSkill: making a USB installer

Install ChromeOS Flex from a USB installer to give an older Windows, Mac or Linux machine a Chromebook-like system. It needs a 16 GB or larger USB drive that gets erased, Google only guarantees function on certified models, and the page is written for admins. Productivity angle: a cheap dedicated browser machine for Sheets or a seller dashboard.

Sourcesupport.google.com
05

Google Docs, Sheets and Slides offline

ChromebookEasySkill: none

Turn on offline access and edit recent files without internet. It needs Chrome or Edge (not private browsing), the Docs Offline extension and free disk space, and only recently opened files are saved. Productivity angle: edit a spreadsheet on the road and let it sync later.

Sourcesupport.google.com
