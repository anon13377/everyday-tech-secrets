Turn off the TV tracking settings

smart TVEasySkill: None

Smart TVs have privacy settings, including ACR (automatic content recognition), that limit what the TV tracks about your viewing. Anyone with a smart TV can use this to cut down on data collected about their household. It takes a few minutes in the settings menu. The catch is that menu names and options differ by brand and model.

Read the originalon news.yahoo.com
02

Sideload any app on a Fire TV with Downloader

smart TVEasySkill: Low

Downloader is an app on Amazon Fire TV that lets you type a web address and install apps that Amazon does not list. You first flip one setting that allows installs from unknown sources. It is useful for tools like file managers or custom launchers. The catch is that you should only install apps you trust, because pirated streaming apps are risky and illegal.

Read the originalon aftvnews.com
03

Strip ads and bloat from a TV with ADB

smart TVMediumSkill: Low

This project uses ADB (a developer tool that talks to Android devices from a computer) to disable ad and tracking apps on an Android TV. The source says to disable packages rather than uninstall them, back up the package list first, and turn ADB debugging off when you are done. It can make the TV cleaner for people comfortable with a command line. It applies to Android TVs only. The catch is that disabling the wrong packages can cause problems.

Read the originalon itsfoss.com
04

Control a Roku from code with ECP

smart TVMediumSkill: Low

Roku's ECP (External Control Protocol) is an official interface that lets a script or button send remote-control commands to a Roku over your home network. Engineers can use it to automate play, pause or app launching. Hobbyists use it to build custom remotes or smart-home actions. The source notes newer Roku OS versions need the Control by mobile apps setting enabled.

Read the originalon developer.roku.com
05

Roku in Home Assistant

smart TVEasySkill: Low

Home Assistant can detect a Roku on your network and add it automatically. Once connected, you can make other things react to it, such as dimming lights when you press play. It brings the TV into the same smart-home system as your other devices. The source is a third-party page, so check the official documentation for current steps.

Read the originalon selorahomes.com
06

LG TV rooting with the Homebrew Channel

smart TVAdvancedSkill: High

Security researchers found ways to unlock certain LG TVs so they run community apps that LG never approved, through the Homebrew Channel project. It lets owners add features and take more control of the TV. The catch is that LG does not support it, it may void the warranty, and many firmwares have been patched, so check firmware status first.

Read the originalon webosbrew.org

Wyze camera to local only with Thingino

Pi-hole: block ads for your whole house

Raspberry PiEasySkill: Low

Pi-hole is free software that runs on a small Raspberry Pi connected to your home router. It works as a filter for web addresses, so requests to known ad and tracking servers are blocked for every device on your network. At home it cleans up ads on phones, smart TVs and laptops without installing anything on each one. For anyone at home it means fewer ads and less tracking with one setup. The catch is that some sites and apps can break, so keep a backup DNS setting handy.

Read the originalon notes.aliciasykes.com
24

RetroPie: turn a Pi into an arcade

Raspberry PiEasySkill: Low

RetroPie is a ready-made software image for a Raspberry Pi that turns it into a retro game console. You write the image to an SD card, plug the Pi into a TV, and play classic games using a regular controller. It is a cheap family project and a fun way to learn about computers. The software is legal, but downloading game files (ROMs) you do not own is not.

Read the originalon tech.yahoo.com
25

Home Assistant on a Pi: one brain for the whole smart home

Raspberry PiMediumSkill: Low

Home Assistant is free software that runs on a Pi and links smart lights, locks, cameras and TVs into one system. You can make devices react to each other, such as dimming lights when a show starts, and much of it works locally without the cloud. People like having one dashboard instead of many separate apps. The source says a Pi with at least 2GB of RAM is needed and that a ready-made image is available in Raspberry Pi Imager. Expect some setup time.

Read the originalon tech.yahoo.com
26

Kiwix hotspot: Wikipedia with no internet

Raspberry PiMediumSkill: Low

Kiwix lets a Raspberry Pi create its own Wi-Fi network that serves a saved copy of Wikipedia to nearby phones. It works with no internet connection, because the content is downloaded ahead of time. It suits classrooms, clinics, camping trips or places with weak signal. The catch is that the content files are large and the copy is only as fresh as your last download.

Read the originalon kiwix.org

Pi flight tracker (PiAware)

Raspberry PiMediumSkill: Low

PiAware is a Raspberry Pi setup that receives the radio signals planes broadcast about their position and shows them live on a map. It needs a Pi, a small antenna and a cheap USB radio dongle. It is a good hobby project for aviation fans and a fun way to see what flies over your home. Receiving these signals is legal in most places, but check your local rules. The source is a wiki page, so details may vary by version.

Read the originalon wiki.openstreetmap.org

Raspberry PiMediumSkill: Low

tar1090 is a free web page you add to a Pi plane tracker that shows aircraft with trails, history and callsigns, like a mini air traffic screen. It reads from the same radio dongle your tracker already uses. Hobbyists and engineers use it to get a clearer, more detailed view of nearby flights. The catch is that only one decoder program should use the radio dongle at a time.

Read the originalon guide.airframes.io

Hyperion: DIY Ambilight for any TV

Hyperion drives an LED strip behind your TV so the wall glows in the colors of what is on screen, similar to Philips Ambilight. A Pi takes the video through a capture dongle and tells the lights what to show. It makes movies and games feel bigger for a modest cost. The catch is that you must buy the LED strip hardware, and streaming apps with copy protection may block the capture.

Read the originalon peyanski.com

MotionEye: Pi as a security camera hub

MotionEye turns a Raspberry Pi and a cheap camera into a home security camera system with motion detection and alerts. Footage stays in your hands instead of a monthly subscription service. It can watch a door, a garage or a pet while you are out. The catch is legal: check local laws on recording people, especially audio, and keep the system password protected.
